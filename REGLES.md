# Règles vérifiées par l'atelier

Ce sont les règles de construction des cartes officielles Konami. Une **Erreur** rend la carte impossible en jeu officiel.
Une **Alerte** signale un écart avec les cartes imprimées. Une **Info** est un simple rappel.

## Monstres

| Élément | Règle |
|---|---|
| Niveau | De 1 à 12 (monstres Normaux, à Effet, Rituels, Fusion, Synchro, Jetons) |
| Rang (Xyz) | De 0 à 13. Les étoiles sont noires et alignées à gauche |
| Classe Lien | Égale au nombre de Flèches Lien (1 minimum). Pas de DEF, pas de Niveau. Aucune carte officielle ne dépasse LINK-6 |
| Pendule | Échelles de 0 à 13, identiques sur les cartes récentes. Impossible pour un monstre Lien ou un Jeton |
| ATK / DEF | Nombre entier ou « ? ». Multiples de 50 sur les cartes officielles |
| Attribut DIVIN | Réservé au Type Bête Divine (et inversement) |
| Flip, Gémeau, Spirit, Toon, Union | Toujours des monstres à Effet (cadre orange). Un Spirit ne peut pas venir de l'Extra Deck |
| Monstre Normal | Texte d'ambiance en italique, sans effet |
| Extra Deck (Fusion, Synchro, Xyz, Lien) | La 1re ligne du texte liste les Matériels |
| Synchro | Les Matériels incluent 1 Syntoniseur |
| Xyz | Les Matériels précisent un Niveau |
| Lien | Le nombre minimum de Matériels ne dépasse pas la Classe Lien |
| Sacrifice | Niveau 5–6 : 1 Sacrifice. Niveau 7 et plus : 2 Sacrifices |

## Ligne de Type

Ordre officiel : `[Type/Invocation/Pendule/Capacité/Syntoniseur/Effet]`. Exemples :
`[Dragon/Synchro/Syntoniseur/Effet]`, `[Magicien/Pendule/Effet]`, `[Guerrier/Fusion]` (Fusion sans effet).

## Magies et Pièges

- Magie : Normale, Continue (∞), Équipement (✚), Terrain (✥), Jeu-Rapide (⚡), Rituelle (✺).
- Piège : Normal, Continu (∞), Contre-Piège (↩).
- Une Magie ou un Piège a toujours un effet.

## Syntaxe des effets (PSCT)

- `condition : coût ; effet`. Les deux-points viennent avant le point-virgule.
- La restriction « une fois par tour » cite le nom exact de la carte entre guillemets : `Vous ne pouvez utiliser cet effet de « Nom » qu'une fois par tour.`

## Construction du Deck (rappel)

- Main Deck : 40 à 60 cartes. Extra Deck : 15 maximum. Side Deck : 15 maximum.
- 3 exemplaires maximum d'une même carte, sauf limitation.
